## Темы и размеры

- Светлая, тёмная и системная темы; пользовательский акцент, прозрачность, отключённые анимации, compact и все варианты скругления.
- Ширина 1440, 1024 и 375 CSS px; масштаб 200%. Камеры не сжимаются ниже 360 px там, где доступно столько места; на узком экране не требуется горизонтальная прокрутка всей страницы.
- Видимые рамки клавиатурного фокуса и читаемый текст в фильтрах, диалогах, пустых состояниях и fallback медиа.

## План

1. Ошибка API: сообщение об ошибке и повтор, а не «планов нет»; повтор после восстановления соединения.
2. Администратор загружает PNG/JPEG до 5 МБ; файл другого формата/размера отклоняется.
3. Разместить камеру щелчком, затем клавиатурой через центр и X/Y. Проверить крайние координаты 0/100 и нестандартное соотношение сторон изображения.
4. Нажатие на маркер открывает поток, не перемещает выбранную камеру. Для охраны нет редактора.
5. Изменить размещение, уйти на видеостену, другую вкладку, выйти из аккаунта, обновить страницу: отмена перехода сохраняет черновик. Подтверждение теряет только черновик.
6. Во время сохранения/удаления переход не разрешается; ошибка сохранения сохраняет черновик.
7. Приостановленная/отключённая камера со старыми detections не получает текущую метку тревоги.

## Правила камеры

- Неудачная загрузка не позволяет сохранить пустые правила.
- Изменения класса/расписания/зоны вызывают предупреждение при Escape, закрытии и смене раздела; отмена оставляет редактор открытым.
- Незавершённая зона не теряется молча при сохранении: её нужно добавить или очистить.
- Enter/Пробел на кадре добавляет вершину в центр; X/Y позволяют настроить её без мыши. Проверить три неколлинеарные вершины и серверный отказ самопересечения.
- Пока запрос сохранения выполняется, поля и геометрия не редактируются. Enter внутри правил не отправляет форму подключения.

## Архив и медиа

- Карточки/список/лента: смена периода, локальный день у полуночи, переход страниц, пустой ответ, неверные даты, confidence 0 и 100.
- Быстрая смена фильтров при медленном API: старый ответ не подменяет новый; старые карточки не доступны под новыми фильтрами.
- Одновременное обновление списка и сохранение проверки: кнопки mutation не разблокируются окончанием GET. Фоновое обновление с неизменными rows не размонтирует форму.
- Удалённый кадр и непроигрываемое видео дают понятный fallback и повтор запроса; без видео показывается фото.
- Во время подготовки CSV/ZIP повторный клик не создаёт второй экспорт; после ошибки кнопки снова доступны. Фоновое обновление архива не снимает выбор сохранившихся событий.
- Диалог инцидента: Tab/Shift+Tab остаются внутри, Escape закрывает, фокус возвращается инициатору. Повторить в полноэкранном режиме охраны.

## Центр тревог

- Начальная загрузка не озвучивает исторические строки; новое событие объявляется один раз.
- Удаление события, расширяющее окно старыми строками, не вызывает ложного нового уведомления.
- После сетевой ошибки видны ошибка и время последнего успешного обновления. Последующий успешный опрос снимает ошибку.
- Сохранение проверки во время опроса планирует повторное обновление, а не теряет его.
- Latest100 не является гарантированной очередью; тест не должен утверждать доставку bursts/задержанных записей.

## Локальные предпочтения

- В отдельном тестовом профиле повредить JSON раскладки: приложение использует стандартную раскладку, не падает.
- Закрепления принимают только положительные целочисленные ID; строки, null, отрицательные и повторяющиеся ID не влияют на видеостену.
- Сохранённые настройки другого сотрудника не применяются после выхода и входа под новой учётной записью.
